# Number Guessing Game

## Requisitos
 - É um jogo baseado em CLI, então você precisa usar a linha de comando para interagir com o jogo. O jogo deve funcionar da seguinte forma:

 - Quando o jogo começar, ele deverá exibir uma mensagem de boas-vindas junto com as regras do jogo.

 - O computador deve selecionar aleatoriamente um número entre 1 e 100.

 - O usuário deve selecionar o nível de dificuldade (fácil, médio, difícil), que determinará o número de chances que ele terá de adivinhar o número.

 - O usuário deve ser capaz de inserir seu palpite.

 - Se o palpite do usuário estiver correto, o jogo deve exibir uma mensagem de felicitações junto com o número de tentativas necessárias para adivinhar o número.

 - Se o palpite do usuário estiver incorreto, o jogo deverá exibir uma mensagem indicando se o número é maior ou menor que o palpite do usuário.

 - O jogo deve terminar quando o usuário adivinhar o número correto ou ficar sem chances.
